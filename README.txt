ANDROID INTERVAL TIMER PWA

Kurulum:
1) Bu klasördeki dosyaları HTTPS üzerinden yayınla.
2) Android telefonda Chrome ile siteyi aç.
3) Sağ üstte ⋮ menüsüne dokun.
4) “Install app” veya “Add to Home screen / Ana ekrana ekle” seç.
5) Install / Ekle de.

Sonra uygulama ana ekranda ikonuyla görünür ve bağımsız uygulama gibi açılır.

Varsayılan:
- 23 tur
- 36 saniye çalışma
- 5 saniye mola
- son 6 saniyede bip
- çalışma/mola geçiş sesleri
- titreşim
- Start / Pause / Reset / Skip
- offline cache

Not: PWA kurulumu için sayfanın HTTPS üzerinden açılması gerekir.
